# 真实语料评测

本目录包含原始 FastAPI 官方中文文档（MIT 许可）、固定提交来源清单、80 道代理编写的初稿问题、隔离评测脚本和逐题结果。

## 语料

- 固定为 FastAPI 0.115.0，对应 manifest.json 中的 commit；避免每次下载最新分支改变实验条件。
- 官方 Markdown 的代码包含指令展开为完整 Python 文件，其他站点特有标记保留。
- 保留 MIT 许可证与每篇文件来源 URL、SHA256；不把第三方内容说成原创。
- 16 篇教程主要为中文，含多种 Python 版本示例，存在重复代码；并非多产品企业语料。

## 标签与指标

64 道可回答题，16 道资料外问题。dev/test 各包含 8 篇文档的 32 道可回答题及 8 道资料外问题。整篇文档分组，跨文档共享基础概念仍可能造成泄漏；尚无多跳或版本冲突评测。

参考答案和证据锚点由代理编写，脚本只能确认锚点存在，不能替代人工标注审核。不要将此结果包装为客户测试集或答案准确率。

检索测试比较 vector、bm25、hybrid、rerank；资料外题不计算召回率，另用有限的回答抽查检查拒答。回答抽查输出完整答案、引用和用量，等待人工审核事实支持性。每个模式只运行一轮，网络延迟波动可能显著。

## 操作

先运行 fetch_corpus.py 下载固定语料，再运行 build_dataset.py 验证标签，最后运行 benchmark.py。所有脚本均从项目根目录运行。benchmark 的默认 split 是 dev；--answers 控制真实生成调用上限，默认为 0。检查原始结果中的 status 与 errors，不仅看平均指标。

评测过程使用单独的本地 Qdrant 数据目录，不上传用户已导入的私人文件。公开语料和测试问题会发往 .env 配置的服务商。硅基流动配置下可以复用 Embedding 密钥测试 BGE 重排；脚本不输出密钥。
